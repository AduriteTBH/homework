HOPTER ROYALE — ASSET SWAP GUIDE
================================

Drop replacement files here using the SAME filename. Reload the game to pick them up.

LOGO (main menu)
  logo.svg          — primary logo (vector, recommended)
  logo.png          — PNG fallback if you prefer raster art

SPRITES
  sprites/hopter.svg       — top-down hopter drawn in-game (default)
  sprites/hopter-ship.png  — optional Kenney CC0 ship sprite (included)
  sprites/hopter.png       — optional PNG hopter (overrides SVG if present)

TEXTURES
  textures/ground-tile.png — repeating map floor tile
  textures/crate.png       — loot crate
  textures/crate-gold.png  — rare crate (copy/rename your gold variant)
  textures/gem.png         — XP pickup
  textures/bullet.png      — projectile

AUDIO (optional — better than built-in synth if you add files)
  audio/menu.mp3  or  menu.ogg   — main menu music (loops)
  audio/battle.mp3 or battle.ogg — in-match music (loops)

Recommended sizes:
  Logo: ~800×200 px (or SVG)
  Hopter sprite: 128×128 px, facing RIGHT
  Tiles: 64×64 or 128×128 px, seamless

Included Kenney assets are CC0 (see LICENSE-KENNEY.txt). Custom SVG logo/hopter are project defaults.
